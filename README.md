## Core Capabilities

| Capability | Description |
|---|---|
| **Groups + Private Chats** | Manage supported group and private-chat cleanup workflows |
| **WhatsApp + Business** | Designed to work with compatible WhatsApp and WhatsApp Business installations |
| **Safe Cleanup** | Confirmation-oriented cleanup workflow with preview controls |
| **Snapshot Management** | Local snapshot reference and recovery-oriented workflow |
| **Network Isolation** | Network isolation controls for supported operations |
| **Live Discovery** | Discover and rescan supported chats and groups |
| **Counter Resync** | Reconcile supported message and unread-state counters |
| **Root Integration** | Root-assisted access for operations that require database-level access |
| **FREE + PRO** | Freely available FREE edition and licensed PRO functionality |

Feature availability may differ between FREE and PRO editions.

## Requirements

- Android 8.0 or later
- Root access for database operations
- Compatible WhatsApp and/or WhatsApp Business installation
- Valid WAGC PRO license for PRO-only functionality

## Installation

1. Download the required APK from the official WAGC GitHub Release.
2. Verify its SHA-256 checksum before installation.
3. Allow installation from the source used to open the APK if Android requests it.
4. Install and launch WAGC.
5. Grant the permissions required by the features you use.
6. Grant root access when requested for database-level operations.
7. For PRO functionality, complete the WAGC licensing process.

### Verify SHA-256 on Windows

```bat
certutil -hashfile "WAGC_V2.5.9_FREE.apk" SHA256
certutil -hashfile "WAGC_V2.5.9_PRO.apk" SHA256
```

Compare the result with the official checksum in the download table above.
