## Core Capabilities

- WhatsApp group discovery and management
- Group cleanup and maintenance tools
- Live Group Discovery V3
- Unread-state handling and reconciliation
- LID / PN handling
- Network isolation controls
- FREE and licensed PRO editions
- Root-assisted database operations

Feature availability may differ between FREE and PRO editions.

## Requirements

- Android 8.0 or later
- Root access for database operations
- Compatible WhatsApp installation
- A valid WAGC license for PRO-only functionality

## Installation

1. Download the required APK only from the official WAGC GitHub Release page.
2. Verify the SHA-256 checksum shown below.
3. Allow APK installation from the source you use to open the downloaded file, if Android requests it.
4. Install the APK.
5. Launch WAGC and grant the required permissions.
6. Grant root access when requested for functions that require database access.
7. PRO users should complete the WAGC licensing process to activate PRO functionality.
