# WAGC Security Policy | سياسة أمان WAGC

## English

### Supported Version
| Version | Supported |
|---|---|
| 2.5.9 | Yes |
| Older versions | No |

Use the latest official WAGC release whenever possible.

### Official Distribution
Official releases are distributed from the [WAGC Releases page](https://github.com/ananalbzoor86/WAGC/releases). Verify the APK SHA-256 checksum before installation.

### Reporting a Security Issue
Do not publish sensitive vulnerability details, credentials, license information, private data, databases, messages, tokens, signing material or exploit details in a public issue.

Use GitHub private vulnerability reporting or security advisory facilities when available. If private reporting is unavailable, contact the project owner privately before publishing technical details.

A useful report should include WAGC edition/version, Android version and device model when relevant, root solution/version, reproduction steps, expected and actual behavior, sanitized logs, security impact and affected functionality.

### Responsible Disclosure
Allow reasonable time for investigation and remediation before public disclosure. Remove personal information, tokens, credentials and private user data from reports.

### APK Integrity
A matching filename does not prove an APK is official. Verify SHA-256. Modified, repackaged or third-party builds are not official WAGC releases unless explicitly identified by the project owner.

### Scope
This public repository contains distribution and documentation material only. WAGC private source code, signing material, licensing implementation and private development history are not distributed here.

### الإبلاغ عن مشكلة أمنية
لا تنشر تفاصيل ثغرات حساسة أو بيانات اعتماد أو معلومات تراخيص أو قواعد بيانات أو رسائل خاصة أو Tokens أو مفاتيح توقيع أو تفاصيل استغلال ضمن Issue عامة.

استخدم ميزة الإبلاغ الخاص عن الثغرات أو Security Advisories في GitHub عندما تكون متاحة. وإذا لم يكن الإبلاغ الخاص متاحاً، تواصل مع مالك المشروع بشكل خاص قبل نشر التفاصيل التقنية.

يفضل أن يتضمن البلاغ إصدار ونسخة WAGC، إصدار Android وطراز الجهاز عند الحاجة، حل Root وإصداره، خطوات إعادة المشكلة، السلوك المتوقع والفعلي، Logs بعد إزالة البيانات الحساسة، وتأثير المشكلة والوظائف المتأثرة.

### الإفصاح المسؤول
يرجى منح وقت مناسب للتحقيق والإصلاح قبل نشر تفاصيل الثغرة علناً، مع إزالة البيانات الشخصية وبيانات الاعتماد والمعلومات الخاصة من أي تقرير.

### سلامة APK
تشابه اسم ملف APK مع الاسم الرسمي لا يعني أنه ملف رسمي. تحقق دائماً من SHA-256. النسخ المعدلة أو المعاد حزمها أو الصادرة من جهات أخرى ليست إصدارات WAGC رسمية إلا إذا أعلن مالك المشروع ذلك صراحة.

### النطاق
هذا المستودع العام مخصص للتوزيع والوثائق فقط. السورس الخاص ومفاتيح التوقيع وآلية الترخيص وسجل التطوير الخاص بـWAGC لا يتم توزيعها من خلال هذا المستودع.
