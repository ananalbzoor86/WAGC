# WAGC Security Policy

## Supported Version

| Version | Supported |
|---|---|
| 2.5.9 | Yes |
| Older versions | No |

Users should use the latest official WAGC release whenever possible.

## Reporting a Security Issue

Please do not publish sensitive vulnerability details, credentials, license information, private data, or exploit details in a public issue.

For a security problem, use GitHub's private vulnerability reporting / security advisory facilities when available for this repository. If private reporting is not available, contact the project owner privately before publishing technical details.

A useful report should include:

- WAGC edition and version.
- Android version and device model when relevant.
- Root solution and version when relevant.
- Clear reproduction steps.
- Expected and actual behavior.
- Relevant logs with personal data, tokens and credentials removed.
- Security impact and affected functionality.

## Responsible Disclosure

Please allow reasonable time for investigation and remediation before public disclosure. Do not include user databases, private messages, authentication material, license credentials, signing material or other sensitive data in reports.

## APK Integrity

Do not trust an APK solely because its filename matches an official WAGC filename. Verify its SHA-256 checksum. Modified, repackaged or third-party builds are not official WAGC releases unless explicitly identified as such by the project owner.

## Scope

This public repository contains distribution and documentation material. The WAGC application source code, signing material, licensing implementation and private development history are not distributed through this repository.
