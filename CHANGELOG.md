# WAGC Changelog | سجل تغييرات WAGC

All notable public WAGC releases are documented here.  
يتم توثيق جميع إصدارات WAGC العامة المهمة في هذا الملف.

## [2.5.9] - 2026-09-18

### English

#### Release
- Published WAGC V2.5.9 in FREE and PRO editions.
- Added Live Group Discovery V3.
- Improved group discovery and management workflow.
- Improved unread-state handling and reconciliation.
- Improved LID / PN handling.
- Included network isolation controls.
- Continued root-assisted database operations.
- PRO edition uses WAGC licensing for PRO functionality.

#### Distribution
- Public repository converted to distribution and documentation only.
- Application source code and private development history are maintained separately.
- Official APK downloads are provided through GitHub Releases.
- SHA-256 checksums are published for release verification.

### العربية

#### الإصدار
- نشر WAGC V2.5.9 بإصداري FREE وPRO.
- إضافة Live Group Discovery V3.
- تحسين اكتشاف المجموعات وسير عمل إدارتها.
- تحسين معالجة ومزامنة حالات الرسائل غير المقروءة.
- تحسين التعامل مع LID / PN.
- تضمين أدوات عزل الشبكة.
- استمرار دعم العمليات التي تحتاج إلى Root للوصول إلى قاعدة البيانات.
- وظائف PRO تتطلب ترخيص WAGC صالحاً.

#### التوزيع
- تم تحويل المستودع العام إلى مستودع للتوزيع والوثائق فقط.
- يتم الاحتفاظ بالسورس الكامل وسجل التطوير الخاص بشكل منفصل.
- ملفات APK الرسمية متاحة من GitHub Releases.
- يتم نشر بصمات SHA-256 للتحقق من سلامة ملفات الإصدار.
