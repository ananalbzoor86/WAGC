# WAGC Changelog

All notable public WAGC releases are documented here.

## [2.5.9] - 2026-09-18

### Release

- Published WAGC V2.5.9 in FREE and PRO editions.
- Added Live Group Discovery V3.
- Improved group discovery and management workflow.
- Improved unread-state handling and reconciliation.
- Improved LID / PN handling.
- Included network isolation controls.
- Continued root-assisted database operations.
- PRO edition uses WAGC licensing for PRO functionality.

### Distribution

- Public repository converted to distribution and documentation only.
- Application source code and private development history are maintained separately.
- Official APK downloads are provided through GitHub Releases.
- SHA-256 checksums are published for release verification.
